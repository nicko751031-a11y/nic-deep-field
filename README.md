# NIC Deep Field｜第一人稱 3D 宇宙探索（測試版）

真實比例、第一人稱、可自由飛行的網頁版宇宙探索。打開即用，不需安裝。
**這是測試版**：所有 3D 畫面皆為模擬；哪些是實際觀測影像、哪些是推算或程序模擬，在畫面中逐一標示。

## 操作

| 裝置 | 操作 |
|---|---|
| 電腦 | `W/S` 前後、`A/D` 左右平移、`R/F`（或 Shift/Ctrl）升降、`Q/E` 翻滾；拖曳畫面或雙擊鎖定滑鼠環視；滾輪／`Z` `X` 調速；空白鍵停止 |
| 手機／平板 | 左半邊拖曳＝移動（虛擬搖桿）、右半邊拖曳＝環視、雙指縮放＝靠近／拉遠、右下 ▲▼ 升降 |
| 共通 | `H` 隱藏／顯示介面（右上角半透明「介面」鈕可找回）、`O` 自動環繞、`V` 重設視角、`B` 返回地球、`G` 全螢幕、`T` 暫停時間、`/` 搜尋 |

- 底部：停止、環繞、靠近／拉遠（按住）、重設視角、返回地球、速度（自動／手動／⚡超光速）、時間倍率與「現在」。
- 搜尋：中文名、英文名、M、NGC、IC、HIP/HD/HR、系外行星名、黑洞名。搜不到會明確說「未收錄」並列出收錄數量，不會虛構。
- 「真實觀測」分頁：太陽（SDO／SOHO）、地球（GOES、Himawari、DSCOVR EPIC）、國際太空站位置、天體位置同步依據。

## 真實與模擬的界線（請務必閱讀）

| 項目 | 性質 | 說明 |
|---|---|---|
| 行星位置、月球位置 | 資料推算 | JPL 近似軌道根數（Standish）、Astronomical Almanac 月球低精度公式；精度角分等級 |
| 自轉軸與自轉相位 | 資料推算 | IAU 2009/2015 自轉模型；地球相位等同格林威治恆星時（已驗證台北日夜與台灣方位）；其他行星貼圖的本初子午線對齊未逐一驗證 |
| 地球、月球、火星、木星、土星、海王星、冥王星貼圖 | 實際觀測影像拼接 | NASA Blue Marble／Black Marble、NASA/JPL 全球圖、New Horizons 全球圖；皆為歷史合成，不是當下樣貌；地球雲層為固定快照 |
| 水星、天王星表面、金星可見光雲層、太陽表面 | 程序模擬 | 建置環境無法取得 MESSENGER 全球圖；天王星幾乎無特徵；金星以厚雲為主（另可切換 Magellan 雷達圖並標示非肉眼所見） |
| 土星環、天王星環 | 程序重建 | 依已知環帶半徑（C/B/卡西尼縫/A/恩克縫/F）生成，環內細節非影像 |
| 恆星背景 | 實際觀測 | HYG v4.1 星表的真實位置與亮度（4.2 萬顆星點）＋ NASA Tycho 全天圖（含銀河） |
| 恆星近景 | 資料推估 | 半徑、顏色由光度與色指數推估，表面為程序模擬 |
| 系外行星 | 推測外觀 | 只有軌道／質量／半徑資料；顏色、雲帶、地貌全為推測，軌道相位未知 |
| 深空天體（星系、星雲、星團） | 型態示意 | 依目錄類型、視大小與方位角生成的示意圖，不是影像也不是立體重建 |
| 黑洞 | 物理近似 | 史瓦西測地線數值積分（光線偏折、透鏡、陰影）；吸積盤為幾何薄盤＋近似都卜勒射束與重力紅移（藝術化配色）；非克爾黑洞 |
| 躍遷、超光速 | 模擬功能 | 距離是真實的，旅行時間被壓縮；真實宇宙無法如此 |
| 聲音 | 預設靜音 | 可選純合成音景或「行星公轉頻率升八度」的資料聲化，兩者都不是錄音 |

## 真實觀測來源（由瀏覽器直接讀取；本站只顯示來源提供的時間）

| 來源 | 類型 | 時間資訊 |
|---|---|---|
| NASA SDO AIA 171／304、HMI | 近即時（約 15 分鐘） | 由 Helioviewer API 取得最接近現在的影像時間；取不到即標示「無法取得」 |
| ESA/NASA SOHO LASCO C2 | 近即時 | 影像內嵌時間戳 |
| NOAA GOES-East GeoColor | 近即時（10 分鐘） | 影像內嵌時間戳 |
| Himawari-9（NICT） | 近即時（10 分鐘） | NICT latest.json |
| NASA DSCOVR EPIC | 歷史／延遲 1–3 天 | EPIC API |
| 國際太空站位置（wheretheiss.at） | 位置同步 | API 時間戳；可標示到 3D 地球上並前往 |
| NASA YouTube 直播 | 直播（嵌入） | 是否正在播、延遲多少無法判定，已標示 |

**建置環境無法連外**（網路白名單只開放 GitHub／npm），因此上述來源在開發期間只驗證了「失敗狀態的呈現」（會清楚顯示失敗、不顯示舊圖），尚未在開發環境驗證成功載入；請在正式網址以瀏覽器實測。

## 目錄收錄範圍（`data/meta.json`）

- 恆星：HYG v4.1，渲染 41,559 顆（≤ 8 等或有專名），可搜尋 8,940 顆（< 6.5 等或有專名）。CC BY-SA 4.0。
- 深空天體：OpenNGC 全部 NGC/IC 13,309 個（含梅西耶 107 個，有距離者 10,792）。CC BY-SA 4.0。距離依序取文獻值（手動整理）、視差、紅移粗估。
- 系外行星：Open Exoplanet Catalogue（2023-10）已確認 5,288 顆。
- 黑洞：8 個（手動整理，含來源）。
- 太陽系：太陽、月球、傳統九大行星（冥王星標示為矮行星）。尚未收錄其他衛星、小行星、彗星。
- 未涵蓋：PGC/UGC 更暗星系、Gaia 完整星表、星系團目錄、NASA Exoplanet Archive 最新發現（建置環境無法連線）。「其他宇宙」沒有可驗證資料，不提供。

重新產生資料：`python3 -I tools/build_data.py --hyg <HYG倉庫> --ngc <OpenNGC倉庫> --oec <oec_tables倉庫> --out data`。

## 執行與部署

- 本機：任何靜態伺服器皆可，例如 `python3 -m http.server 8123`，開啟 `http://127.0.0.1:8123/`。
- Node：`npm start`（`server.js`，預設 port 3000；設定 `SITE_USER`／`SITE_PASSWORD` 即啟用 Basic 認證，預設公開）。
- 畫質會依裝置自動選擇（高／中／低），可在設定中更改；低畫質關閉泛光、降低星球細分與黑洞步數。

## 已知限制

- 貼圖解析度 720–4096 px，近距離會模糊；「程序細節」只調變亮度，不是真實地形。
- 相對論效果（光行差、都卜勒）未在飛行時模擬；光速效果只是放射狀星光拉絲。
- 深空天體與系外行星只有示意／推測外觀；黑洞為無自轉近似。
- 行星環對行星的影子、行星對環的影子為幾何投影近似；大氣為單次散射近似。
- 真實觀測來源可能因對方停機、網址變更或 CORS 失敗；失敗時明示，不以舊圖冒充。
- 測試紀錄見 `TESTING.md`。
