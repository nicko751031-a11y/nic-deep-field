# ARC 網站缺點總表與優化進度（2026-10-27 起持續更新）

負責人要求：「列出網站的各項缺點，包含 UI 與 UX，並持續優化到 100% 完美」。本表由 Claude（工程／QA）維護；
視覺與 UX 項目依協作分工交 GPT（視覺／UX 主導）處理，工程項目由 Claude 處理。每一項都標示
**狀態**（✅ 已修、🔧 本輪修正中、📋 待辦、🔍 需真機確認）、**負責**（Claude／GPT／負責人）與**證據**。

「100% 完美」沒有終點：本表每輪檢查都會新增發現、更新狀態，並把未解決項目留在表上，不會為了好看而刪除。

## 本輪（`claude/stability-flicker`）變更摘要

- 引擎：context lost 恢復與自動降級、像素總量上限、composer MSAA（畫布 antialias 改關）、`setPost()` 安全模式、`scanNonFinite()` 掃描。
- 著色器：`SAFE_GLSL`（`safeColor`／`safeNormalize`）套用到全部 9 個片段著色器。
- 介面：安全模式開關＋診斷連結、favicon／manifest／og、減少動態效果、2D 畫布省電。
- 工具：`tools/nan_sweep.mjs`（11 場景 NaN／黑幀掃描）。
- 測試：見 `TESTING.md`「黑屏閃爍排查」。
